If something has gone wrong with a run

There is a button in the panel that makes this quick. Open Hush, expand Advanced, and press Export Analysis. It saves one JSON file to your Desktop containing the levels, the decisions Hush made and the full activity log from the last run.

Attach that file and I can usually see what happened without a single follow‑up question. It contains no audio — only measurements — so you are not sending me your recording.

It also helps to say:

  • which version of Premiere, and which macOS
  • how the audio was recorded — one multichannel file, or separate files per microphone, and whether the recorders started together
  • what you expected to happen, and what happened instead

Before you write about the preview looking darker

This one comes up often enough to answer here. The rebuilt sequence can preview darker than your original, because Premiere's XML importer leaves its Color Setup on “Custom”. Fix it in Sequence Settings → Color Management → Color Setup, set to match the original, usually “Direct Rec. 709 (SDR)”.

Your export is not affected — only the preview.

Feature requests and awkward recordings

Both welcome. Hush has been tuned against real hand‑labelled sessions rather than synthetic tests, and the hard cases came from actual recordings that did not work. If you have a session it handles badly, that is genuinely useful to hear about.
